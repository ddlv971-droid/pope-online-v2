V8 - Analyse des pièces jointes pour la génération

Cette version ajoute la capacité d'analyse des pièces déposées dans le coffre 48h lorsqu'elles sont sélectionnées pour la génération, côté public comme privé.

Formats désormais analysables dans la génération :
- TXT
- DOC
- CSV
- PDF

Important :
- l'analyse des PDF et DOC repose sur une extraction texte embarquée légère, pensée pour rester compatible avec le projet sans dépendance supplémentaire ; la qualité dépend donc du document source.
- les parcours existants de génération, relecture experte, accompagnement sur mesure et dépôt sécurisé sont conservés.
