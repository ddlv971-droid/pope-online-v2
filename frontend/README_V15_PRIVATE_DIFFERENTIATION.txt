V15 — Différenciation renforcée de l’espace privé

Objectif principal
- Différencier clairement l’offre privée par rapport au public.
- Injecter dans l’interface des cas d’usage plus proches des artisans, indépendants et TPE.
- Mieux exploiter le dépôt sécurisé 48h dans les usages privés, notamment pour les marchés publics.

Modifications majeures
1. Dashboard privé
- Carte principale recentrée sur trois familles de besoins privées :
  - Marchés publics
  - Courriers administratifs
  - Formalités d’entreprise
- Texte interface enrichi avec des repères métier issus des parcours officiels Urssaf, Bpifrance Création, commande publique et CCI.

2. Génération IA privée
- Nouvelle différenciation des assistants privés :
  - Réponse à un marché public (DCE / RC / offre)
  - Courrier URSSAF / cotisations / délai / contestation
  - Courrier impôts / TVA / SIE / réclamation
  - Courrier banque / trésorerie / justificatifs
  - Courrier client / fournisseur / relance / mise au point
  - Courrier formalités / greffe / CCI / INPI
  - Création d’entreprise / lancement d’activité
  - Modification d’entreprise / siège / activité / dirigeants
  - Formalités sociales / embauche / documents / affiliation
  - Synthèse / cadrage / check-list de dossier
- Pour chaque assistant privé :
  - texte d’aide métier
  - cas représentatifs
  - placeholders adaptés
  - copie spécifique pour les pièces 48h

3. Dépôt sécurisé 48h
- Adaptation du wording au privé : DCE, RC, justificatifs, statuts, pièces de formalité, courriers reçus.

4. Relecture experte et accompagnement
- Textes adaptés au privé.
- Les demandes privées peuvent continuer à joindre :
  - une génération archivée
  - des pièces du dépôt sécurisé 48h

5. Prompt IA
- Différenciation du prompt système public / privé.
- Ajout d’instructions dédiées aux marchés publics, courriers administratifs et formalités d’entreprise.
