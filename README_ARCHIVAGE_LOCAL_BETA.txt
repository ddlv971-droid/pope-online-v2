POPE Online — Beta avec archivage local des générations IA

Nouveauté intégrée :
- historique des prompts et des générations IA conservé côté navigateur du client ;
- aucune table SQL ni stockage serveur supplémentaire ;
- segmentation par compte connecté ;
- réouverture d'une archive dans le formulaire ;
- export JSON local ;
- import JSON local ;
- suppression unitaire et vidage complet de l'historique local.

Important :
- les archives restent sur l'appareil et dans le navigateur utilisé ;
- si le client change d'ordinateur, de navigateur ou vide ses données locales, l'historique disparaît ;
- l'export JSON permet une sauvegarde manuelle et une restauration ultérieure.
