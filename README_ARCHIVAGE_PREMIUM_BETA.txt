POPE Online — Archivage local premium

Cette version ajoute un archivage local enrichi, sans stockage supplémentaire côté SaaS.

Nouveautés :
- filtres par date (du / au)
- tri (récents, anciens, titre, favoris)
- classement par type de livrable
- favoris
- renommage des archives
- tuiles de synthèse (total, affichées, favoris, types)
- export/import JSON conservés
- archivage toujours local au navigateur du client

Important :
- aucune archive n’est envoyée au serveur pour cet historique
- les archives restent liées au navigateur/appareil du client
- l’export JSON est recommandé pour sauvegarder l’historique
